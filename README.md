# Проект masks_date

## Описание:

Проект masks_date - это тестовое приложение для проведения банковских операций пользователем.

## Установка:

1. Клонируйте репозиторий:
    ```
    https://github.com/ViktorPilot/masks-date.git
    ```
2. Запустите PyCharm у себя на компьютере.
3. Откройте скачанный репозиторий в PyCharm.
4. Зависимости установятся автоматически при открытии скачанного репозитория.
5. Программа готова к работе.

## Использование:

### Для модуля widget.py:

1. В Python файле `widget.py` необходимо ввести номер счета (карты) `card_info`  в формате
   `"Счет 64686473678894779589"`,
   а также дату `date` в формате `"2024-03-11T02:26:18.671407"`.
2. Запустить выполнение программы командой `python -m src.widget`.
3. В результате получим зашифрованный номер счета `Счет **9589` и дату в формате `11.03.2024`.

### Для модуля masks.py:

1. В Python файле `masks.py` необходимо ввести номер счета `card_number` в формате `"7000792289606361"`
   и номер карты `count_number` в формате `"73654108430135874305"`.
2. Запустить выполнение программы командой `python -m src.masks`.
3. В результате получим зашифрованный номер карты `7000 79** **** 6361` и счета `**4305`.

### Для модуля processing.py:

1. В Python файле `processing.py` необходимо ввести список словарей в формате
   ```
   [{"id": 41428829, "state": "EXECUTED", "date": "2019-07-03T18:35:29.512364"},
   {"id": 939719570, "state": "EXECUTED", "date": "2018-06-30T02:08:58.425572"}]
   ```
2. Запустить выполнение программы командой `python src\processing.py`.
3. В результате получим список словарей с заданным статусом и список словарей отсортированных по дате.

### Для модуля generators.py:

1. В Python файле `generators.py` необходимо ввести список транзакций `transactions` в формате
   ```
   [
   {
       "id": 939719570,
       "state": "EXECUTED",
       "date": "2018-06-30T02:08:58.425572",
       "operationAmount": {"amount": "9824.07", "currency": {"name": "USD", "code": "USD"}},
       "description": "Перевод организации",
       "from": "Счет 75106830613657916952",
       "to": "Счет 11776614605963066702",
   }]
   ```
   тип валюты `type_currency` в формате ```USD```, начальное и конечное значение диапазона генерации номеров карт
   `card_number_generator` в целочисленном формате `1, 5`.
2. Запустить выполнение программы командой `python src\generators.py`.
3. В результате получим список транзакций с заданным значением валюты, список всех проведенных операций и
   сгенерированные значения номеров карт в заданном диапазоне.

## Тестирование:

Данный проект покрыт юнит-тестами с использованием фреймворка pytest.
Для их запуска выполните команду `poetry run pytest` из корневой директории проекта.

### Реализованы:

### Для модуля widget.py:

+ Проверка работы функции, возвращающей зашифрованный номер карты или счета при стандартных значениях.
+ Проверка работы функции, вызывающей исключение при вводе номера карты или счета
  с количеством символов, отличным от заданных значений.
+ Проверка работы функции, вызывающей исключение при вводе пустой строки.
+ Проверка работы функции, вызывающей исключение при вводе номера карты или счета
  без указания типа карты или счета.
+ Проверка работы функции, вызывающей исключение при вводе номера счета со значениями,
  отличными от целого числа.
+ Проверка работы функции, изменяющей формат вывода даты при стандартных значениях.
+ Проверка работы функции, вызывающей исключение при вводе значений с нестандартным количеством символов.
+ Проверка работы функции, вызывающей исключение при вводе значений даты вне диапазона возможных значений.
+ Проверка работы функции, вызывающей исключение при вводе даты, отличной от целого числа.

### Для модуля masks.py:

+ Проверка работы функции, возвращающей зашифрованный номер карты при стандартных значениях.
+ Проверка работы функции, вызывающей исключение при вводе номера карты с меньшим количеством символов.
+ Проверка работы функции, вызывающей исключение при вводе номера карты с большим количеством символов.
+ Проверка работы функции, вызывающей исключение при вводе номера карты со значениями,
  отличными от целого числа.
+ Проверка работы функции, возвращающей зашифрованный номер счета при стандартных значениях.
+ Проверка работы функции, вызывающей исключение при вводе номера счета
  с количеством символов, отличным от заданного.
+ Проверка работы функции, вызывающей исключение при вводе номера счета со значениями,
  отличными от целого числа.

### Для модуля processing.py:

+ Проверка работы функции, возвращающей список словарей с заданным статусом 'EXECUTED'.
+ Проверка работы функции, возвращающей список словарей с заданным статусом 'CANCELED'.
+ Проверка работы функции, не содержащей значений с заданным статусом 'EXECUTED'.
+ Проверка работы функции, не содержащей значений с заданным статусом 'CANCELED'.
+ Проверка работы функции с заданным статусом 'EXECUTED' при отсутствии в одном из словарей ключа 'state'.
+ Проверка работы функции с заданным статусом 'CANCELED' при отсутствии в одном из словарей ключа 'state'.
+ Проверка работы функции, возвращающая список словарей отсортированных по уменьшению значений даты.
+ Проверка работы функции, возвращающая список словарей отсортированных по возрастанию значений даты.
+ Проверка работы функции, возвращающая список словарей при одинаковых
  значениях даты с типом сортировки по умолчанию.
+ Проверка работы функции, возвращающая список словарей при одинаковых
  значениях даты с типом сортировки на возрастание значений даты.
+ Проверка работы функции, вызывающей исключение при недопустимых значениях даты.

### Для модуля generators.py:

+ Проверка работы функции, возвращающей итератор с заданным значением валюты при стандартных значениях.
+ Проверка работы функции, при отсутствии в списке заданного типа валюты.
+ Проверка работы функции, при пустом списке транзакций в валюте 'RUB'.
+ Проверка работы функции, при пустом списке транзакций в валюте 'USD'.
+ Проверка работы функции, при отсутствии транзакций в валюте 'USD'.
+ Проверка работы функции, возвращающей описание операции при выполнении одной транзакции.
+ Проверка работы функции, возвращающей описание операций при выполнении двух транзакций.
+ Проверка работы функции, возвращающей описание операций при выполнении пяти транзакций.
+ Проверка работы функции, возвращающей список проведенных операций при выполнении пяти транзакций.
+ Проверка работы функции, при отсутствии транзакций.
+ Проверка работы функции, генерирующей номера карт при стандартных значениях.
+ Проверка работы функции, вызывающей исключение при вводе значений start/stop вне допустимого диапазона.
